# engram scaffold bootstrap — handoff

**Date:** 2026-10-01 · **Branch/Commit:** main @ bootstrap · **Duration:** single session

## Where we ended

`engram` v0.1 is implemented, self-hosted and tested. The repository now *is* the tool's first
customer: `.ai/` here was generated by `engram init` from this repo's own templates, then filled with
real content. Remaining work is identity and release, not architecture.

## What changed

| File / area | Change | Why |
| --- | --- | --- |
| `src/templates/contract.ts` | `AI_CONTRACT` constant + idempotent `withContract` / `refreshContract` | contract must be identical in every tool and survive re-runs |
| `src/templates/skills.ts` | four canonical specs, Agent Skills frontmatter | single source for `/handoff`, `/remember-pitfall`, `/remember-decision`, `/audit` |
| `src/adapters/index.ts` | 8 tool definitions: rule files, skill sinks, style guides | cross-tool coverage without per-tool skill copies |
| `src/adapters/rules.ts`, `skills.ts` | render + refresh rule files, materialise carriers | `init` and `sync` share one code path |
| `src/core/fingerprint.ts` | section-priority byte budgeting | hard ≤1.5 KB guarantee, degrades instead of truncating mid-sentence |
| `src/core/memory.ts` | tolerant Markdown parsing of `.ai/` | `dump` must never throw on a messy file |
| `src/commands/*` | `init`, `dump`, `new`, `sync` | the whole CLI surface |
| `.ai/`, `.engram/`, `AGENTS.md`, `CLAUDE.md`, … | generated bank + tool contracts | dogfooding is the only honest test of the template quality |

## Do not repeat

- Do not let the model author the contract block: see `decisions/2026-10-01-contract-block-machine-owned.md`.
- Do not author skills per tool: see `decisions/2026-10-01-canonical-skills-single-source.md`.
- Do not add a runtime dependency: see `decisions/2026-10-01-zero-runtime-dependencies.md`.
- `tsconfig.json` `outDir` and `package.json` `bin` must be the same path — see
  `pitfalls/cases/tsc-wrong-outdir.md`.
